# Sales Summary Project

## Overview
This project uses SQLite, Pandas, and Matplotlib in Python to create a simple sales database, run SQL queries, and visualize basic sales information.  
The entire project is built and tested in **Google Colab**.

## Steps
- Create a `sales` table with sample product sales.
- Run SQL queries to get total quantity sold and total revenue per product.
- Display the results using `print`.
- Create a bar chart of revenue by product.
- Save outputs (database file and chart image).

## Files
- `sales_data.db` - SQLite database containing sales data.
- `sales_chart.png` - Bar chart showing revenue per product.
- `sales_summary.ipynb` - Colab Notebook with complete code and explanation.

## Tools Used
- Python
- SQLite (via `sqlite3` module)
- Pandas
- Matplotlib
- Google Colab
